Projects

A look at what I've built so far — all academic projects from my time at ESPRIT.

🏭

Mini-APS — CSV to PostgreSQL

A miniature Advanced Planning System: migrates an industrial data pipeline from flat CSV files to PostgreSQL with row-by-row validation and transactional integrity, schedules production with a greedy engine, and computes KPIs (service rate, load vs capacity) in pure SQL through a dedicated Data Access Layer.

Python PostgreSQL SQL psycopg2
🌾

AgriCore — Desktop App

A complete agricultural management platform (JavaFX + MySQL, MVC) helping farmers run daily operations: livestock tracking with health monitoring, equipment & maintenance management, event organization and financial reporting — plus multi-method authentication (Google, GitHub, facial recognition) and a built-in chatbot assistant. Team project, PIDEV 3A30.

Java JavaFX MySQL MVC
🌐

AgriCore — Web App

The full-stack web counterpart of AgriCore, built with Symfony on an MVC architecture: user profiles with QR-code sharing and avatar generation, CAPTCHA-protected authentication with social login, and the same farm-management modules delivered through a Twig front-end. Team project, PIWEB 3A30.

Symfony PHP Twig MySQL
